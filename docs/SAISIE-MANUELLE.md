# Saisie manuelle des courses

Un membre du staff peut saisir une course française depuis `/admin`, sans identifiants The Racing API.

Pour chaque course, renseigner la réunion, l’hippodrome, le numéro de course, le nom, l’heure de départ et les partants. Les champs jockey, entraîneur, distance et surface sont facultatifs. Cocher « NP » pour un non-partant.

Pour corriger une course déjà saisie, reprendre la même date, le même hippodrome et le même numéro de course. Les partants qui ne figurent plus dans la nouvelle saisie sont retirés. Une modification des données retire les pronostics déjà publiés afin qu’ils soient revérifiés.

Indiquer la source et confirmer les droits de publication. Ne pas recopier les données de Turfoo ou d’un autre site sans autorisation écrite. La saisie manuelle ne récupère aucune donnée automatiquement.
